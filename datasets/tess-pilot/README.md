# Пилотный набор TESS

Метки кандидатов взяты из Gaia DR3 через VizieR, таблицы I/358/vrrlyr и
I/358/veb. Запрос охватывает круг радиусом 5° вокруг RA 291.3663°, Dec
42.7844°. В CSV оставлены 36 ближайших кандидатов каждой категории из
выдачи запроса с лимитом 100 строк на таблицу. Это выборка для проверки
конвейера, а не репрезентативный срез всей популяции.

- [Gaia DR3 в VizieR](https://vizier.cfa.harvard.edu/viz-bin/VizieR-3?-source=I%2F358)
- [MAST TESScut](https://mast.stsci.edu/tesscut/)

Для воспроизведения исходных FITS и фотометрии из корня репозитория:

```sh
uv run python scripts/build_tess_pilot.py datasets/tess-pilot/gaia-candidates.csv --out data/tess-pilot
```

Скрипт проверяет сектор 14, запрашивает вырезки 15×15 пикселей и получает
координаты цели из WCS. В манифест попадают серии с вычислимыми признаками,
не менее чем 100 пригодными кадрами и не менее чем половиной пригодных
кадров. Это технический контроль, он не подтверждает отсутствие
смешения источников и не заменяет проверку по независимой фотометрии.
Исходные FITS остаются в локальном `data/`.

`local-examples.csv` и четыре соседних CSV — измерения на ранее скачанных
сериях для RR Lyrae, Beta Lyrae и Delta Cephei. Они годятся для демонстрации
и проверки экспорта. Два сектора RR Lyrae принадлежат одной звезде.

## Обучение на сохранённых кривых

`manifest.csv` содержит 24 независимых объекта, по 12 RR Лиры и затменных
двойных. Папка `curves/` содержит извлечённые измерения. Манифест хранит
Gaia source ID, класс, координаты, URL и SHA-256 исходного FITS, а также SHA-256
CSV. В тренировке используются 21 187 пригодных измерений. Список отклонённых
загрузок и серий сохранён в `rejected.json`.

```sh
uv sync --locked --python 3.12
uv run --no-sync starclass train datasets/tess-pilot/manifest.csv --out models/tess-pilot-v1
```

Команда читает сохранённые измерения и проверяет их контрольные суммы.
Исходные FITS для этого запуска не нужны. Для повторной фотометрии используйте
манифест из `data/tess-pilot/`, который создаёт скрипт скачивания.

Контрольный запуск с seed 42 разбил набор на 14 обучающих, 5 валидационных и
5 тестовых звёзд. Random Forest получил Accuracy 0.60 и Macro-F1 0.583 на
тесте. При пяти тестовых звёздах эти значения подходят для проверки запуска,
но не для выводов о качестве модели.
