# Распознавание переменных звёзд

Классификация кривых блеска переменных звёзд по 6 астрофизическим типам с помощью ансамбля Random Forest (300 деревьев).

## Требования

- Python 3.10+
- Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Структура проекта

```
.
├── data/               # Сгенерированный датасет (dataset.csv)
├── models/             # Обученная модель (rf.joblib)
├── src/
│   ├── simulation.py   # Генерация синтетических кривых блеска
│   ├── preprocess.py   # Предобработка: 3σ, ресемплинг N=1024, окно Ханна
│   ├── features.py     # Извлечение 23 признаков (БПФ, статистика, автокорреляция)
│   ├── train.py        # Обучение Random Forest и метрики
│   ├── predict.py      # Инференс одной кривой
│   └── cli.py          # Консольный интерфейс
├── requirements.txt
└── README.md
```

## Быстрый старт

### 1. Сгенерировать датасет

```
python -m src.cli generate --out data/dataset.csv
```

Создаёт 1200 синтетических кривых блеска (по 200 на каждый из 6 классов).

### 2. Обучить модель

```
python -m src.cli train --data data/dataset.csv
```

Выводит Accuracy, Macro-F1, матрицу ошибок и отчёт по классам. Модель сохраняется в `models/rf.joblib`.

### 3. Классифицировать кривую

```
# Сгенерировать тестовую кривую нужного класса
python -m src.cli predict --cls cepheid

# Или классифицировать собственную кривую из CSV (колонки t и mag)
python -m src.cli predict --file my_curve.csv
```

## Классы звёзд

| Класс ↕▾ | Описание ↕▾ |
|---|---|
| −`cepheid` | Цефеиды — пульсирующие гиганты, период 1–50 суток |
| −`eclipsing_binary` | Затменные двойные — периодические глубокие минимумы |
| −`rr_lyrae` | RR Лиры — короткопериодические пульсаторы (0.2–1 сутки) |
| −`mira` | Мириды — долгопериодические гиганты (100–1000 дней) |
| −`delta_scuti` | Дельта Щита — мультипериодические низкоамплитудные |
| −`solar_like` | Солнцеподобные — стохастические конвекционные колебания |
⚙

## Признаки (23 шт.)

- **Спектральные (БПФ):** топ-3 гармоники (частота, амплитуда, ширина), среднее/стандартное/максимум спектра.
- **Статистические:** среднее, std, асимметрия, эксцесс, полная амплитуда.
- **Спектральные характеристики:** энтропия, центроид, ширина, число пиков.
- **Автокорреляция:** первый пик (лаг и значение).

## Результаты

На тестовой выборке (25%, 300 кривых):

- **Accuracy:** 0.9967
- **Macro-F1:** 0.9967
- **Время обучения:** ~1 с на CPU
