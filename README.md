# Starclass

Starclass открывает серию астрономических снимков TESS, измеряет яркость выбранной звезды и строит кривую блеска. В настольном интерфейсе можно определить предполагаемый тип переменности и сохранить измерения в CSV.

## Открыть приложение

Скачайте или клонируйте репозиторий и откройте терминал в его корневой
папке, где лежат `README.md` и `pyproject.toml`. Например, если папка
репозитория находится в текущем каталоге:

```sh
cd variable-stars-classification
```

При первом запуске установите зависимости. Нужны Python 3.12 и `uv`.

```sh
uv sync --locked --python 3.12 --extra gui
```

Чтобы открыть окно приложения, выполните:

```sh
uv run --no-sync starclass gui
```

В следующий раз достаточно перейти в папку проекта и выполнить команду запуска.

## Первый результат в интерфейсе

Для примера скачайте [серию RR Lyrae из архива MAST](https://mast.stsci.edu/tesscut/api/v0.1/astrocut?ra=291.3663&dec=42.7844&x=15&y=15&units=px&sector=14)
и распакуйте ZIP в любую удобную папку. Если серия уже скачана, используйте
имеющийся FITS. Для классификации понадобится локальная модель. Если вы
запускаете проект впервые, обучите её по инструкции ниже.

1. Нажмите **«Открыть FITS»** вверху справа. Для первого запуска выберите файл `tess-s0014-2-3_291.366300_42.784400_15x15_astrocut.fits` из распакованного архива. Это серия кадров RR Lyrae, на которой проверялось автоматическое обнаружение.
2. В правой панели под надписью **«Источник»** выберите найденный объект из списка или кликните по его голубому кружку на снимке. У выбранного объекта появится оранжевая апертура.
3. Установите **«Радиус апертуры, пиксели»** на **2,00** и нажмите **«Измерить яркость»**. Дождитесь появления графика под снимком. Каждая точка — измерение потока звезды на одном пригодном кадре.
4. Нажмите **«Открыть доверенную модель»**. Выберите **папку** `models/tess-pilot-v2` внутри репозитория и подтвердите выбор. Если папки с обученной моделью ещё нет, воспользуйтесь инструкцией ниже.
5. Нажмите **«Определить тип»**. Справа появятся оценки для двух классов: `rr_lyrae` — RR Лиры и `eclipsing_binary` — затменная двойная. При оценке лидирующего класса ниже 70% пилотная модель показывает **«Неуверенная классификация»**.
6. Чтобы сохранить измерения, нажмите **«Экспорт CSV»**. В файле будут также причины исключения кадров.

Ползунок под снимком переключает кадры. В списке под надписью **«Результат»** можно выбрать, в каких единицах отображать кривую.

## Обучить модель в приложении

Если модель уже есть, сразу открывайте её на шаге 4. Для первого обучения используйте поставляемый датасет из 24 звёзд.

1. В верхнем меню приложения выберите **«Модель» → «Обучить по манифесту…»**. На macOS меню находится в верхней строке экрана.
2. Откройте `datasets/tess-pilot/manifest.csv` из репозитория.
3. В диалоге **«Новая папка модели»** выберите, где сохранить модель. Чтобы использовать путь из шага 4, создайте папку `models` в корне репозитория, откройте её в диалоге и введите имя `tess-pilot-v2`. Если папка модели с таким именем уже существует, выберите другое имя.
4. Дождитесь сообщения **«Модель обучена»**. Приложение автоматически выберет эту модель для текущего сеанса. При следующем запуске её можно открыть кнопкой **«Открыть доверенную модель»**.

Манифест ссылается на измерения, уже извлечённые из снимков TESS. Для этого обучения скачивать FITS заново не нужно. Пилот различает два типа и проверялся на пяти отложенных звёздах. [Датасет и результаты проверки](datasets/tess-pilot/README.md).

## Если кнопка серая или результат не появился

| Что видно | Что сделать |
|---|---|
| Список **«Источник»** серый | Поставьте галочку **«Выбрать точку вручную»** и кликните по центру нужной звезды. На примере Beta Lyrae из сектора 14 это примерно `x = 8, y = 7,6`. |
| **«Измерить яркость»** серая | Выберите найденный объект или укажите точку вручную. |
| **«Определить тип»** серая | Дождитесь окончания измерений и откройте папку обученной модели. |
| После изменения радиуса пропал график | Запустите измерение заново. Для пилотной модели используйте радиус **2,00**. |
| Нет пригодных измерений или кривая сильно шумит | Для первого теста откройте RR Lyrae из сектора 14. У ярких целей свет может выходить за апертуру и попадать в кольцо оценки фона. |
| **«Неуверенная классификация»** | Посмотрите оценки классов справа. Этот статус означает, что оценка лидирующего класса ниже порога модели. |

## Команды для автоматизации

GUI — основной способ работы. Эти команды пригодятся для повторяемых экспериментов из терминала:

```sh
uv run --no-sync starclass inspect path/to/series.fits
uv run --no-sync starclass extract path/to/series.fits --xy 7.6 7.5 --out data/curve.csv
uv run --no-sync starclass train datasets/tess-pilot/manifest.csv --out models/tess-pilot-cli
uv run --no-sync starclass predict path/to/series.fits --xy 7.6 7.5 --trusted-model models/tess-pilot-cli
```

Поддерживаются табличные серии TESScut и TESS TPF. Координаты `x, y` считаются с нуля и соответствуют колонке и строке кадра. Для обучения на собственных FITS подготовьте манифест с полями `path,object_id,label,x,y`. Пути задаются относительно манифеста. Используйте одинаковый `object_id` для всех секторов одной звезды. Нужны минимум два класса и не менее десяти пригодных звёзд в каждом.
