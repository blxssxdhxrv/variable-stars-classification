# Starclass

Настольное приложение для измерения яркости звезды по серии изображений TESS
и классификации переменности по извлечённой кривой блеска.

## Запуск

Нужны Python 3.12 и uv.

```sh
uv sync --locked --python 3.12 --extra gui --extra dev
uv run --no-sync starclass gui
```

Откройте распакованный FITS из соседней папки `../snapshots`, выберите
найденный источник и нажмите «Измерить яркость». Измерения и причины исключения
кадров можно сохранить в CSV. Для просмотра отдельного кадра используйте ползунок.
Если автоматическая детекция не выделила нужную звезду, можно поставить апертуру вручную.

## Командная строка

```sh
uv run --no-sync starclass inspect path/to/series.fits
uv run --no-sync starclass extract path/to/series.fits --xy 7.6 7.5 --out data/curve.csv
uv run --no-sync starclass train data/manifest.csv --out models/tess-v1
uv run --no-sync starclass predict path/to/series.fits --xy 7.6 7.5 --trusted-model models/tess-v1
```

Координаты x/y начинаются с нуля и соответствуют колонке и строке кадра.
Для обучения нужен CSV с полями `path,object_id,label,x,y`. Путь задаётся
относительно манифеста. Используйте один object_id для всех секторов звезды.
Метки берутся из проверенного каталога, координаты соответствуют опорному кадру
конкретной серии. Требуется минимум 10 пригодных объектов на класс и минимум два класса.
Программа извлекает кривые из FITS, разделяет выборку по объектам и сохраняет
результаты Random Forest и двух базовых методов. Загружайте только собственные
модели joblib. Порог оценки модели 0.70 предварительный.

## Текущее покрытие

Поддерживаются табличные кубы TESScut и TESS TPF, апертурная фотометрия и
ограниченное уточнение центроида. Для пограничных, насыщенных и смешанных
источников требуется отдельная проверка апертуры. Четыре демонстрационные серии годятся для проверки загрузки и измерений.
Источники данных, доступные примеры и команды воспроизведения описаны в
[документации пилота TESS](datasets/tess-pilot/README.md).

Исходный синтетический эксперимент сохранён в `src/` и запускается через
`python -m src.cli`. Его результаты не характеризуют качество на TESS.
Полный проектный замысел описан в [плане реализации](docs/IMPLEMENTATION_PLAN.md).
